# Privacy Policy / プライバシーポリシー

Applies to: **Scheduled Banner for Jira** and **Scheduled Banner for Confluence** (the "Apps")
Provider: NAMINOL LLC (NAMINOL合同会社)
Last updated: 2026-10-06

## English

1. **Data the Apps store**
   - Announcements registered by administrators: message, start and end date/time, time zone, and display settings.
     - Jira app: stored in Jira app properties of your site.
     - Confluence app: stored as a space property of the space chosen by an administrator.
   - Confluence app only: the IDs of announcements each user has dismissed, stored in that user's user property (an area private to the App).
2. **Where data is stored**: All data stays inside your Atlassian Cloud site. The Apps run on Atlassian Forge, make no external network requests, and send no data to the provider or any third party.
3. **Use of data**: Only to show and hide announcement banners.
4. **Sharing**: We do not sell or share any data with third parties.
5. **Deletion**: Uninstalling the Apps does not remove data stored in your site. Delete announcements from the App's admin page. For the Confluence app, also remove the `announcement-banner` label from the storage space.
6. **Contact**: masaki_hori@naminol.com

## 日本語

1. **保存する情報**
   - 管理者が登録したお知らせ（本文、開始・終了日時、タイムゾーン、表示設定）。
     - Jira 版：お客様の Jira サイトのアプリプロパティに保存します。
     - Confluence 版：管理者が指定したスペースのスペースプロパティに保存します。
   - Confluence 版のみ：各ユーザーが閉じたお知らせの ID。そのユーザーのユーザープロパティ（本アプリ専用の領域）に保存します。
2. **保存場所**：すべてお客様の Atlassian Cloud サイト内に保存されます。本アプリは Atlassian Forge 上で動作し、外部への通信を行いません。提供者や第三者にデータを送信しません。
3. **利用目的**：お知らせバナーの表示・非表示のためだけに使用します。
4. **第三者提供**：行いません。
5. **削除**：アンインストールしても、サイト内に保存したデータは残ります。管理画面からお知らせを削除してください。Confluence 版は、保存先スペースのラベル `announcement-banner` も外してください。
6. **お問い合わせ**：masaki_hori@naminol.com

NAMINOL合同会社の一般的なプライバシーポリシー: https://naminol.com/privacy-policy
